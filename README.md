## The finder

"Deal Lantern" lists 28 verified Black Friday deals with prices checked
against their pre-sale levels, so each deal shows a real discount rather
than a marketing claim. Shoppers can browse all deals, filter them, and
see a verdict on each one — whether the price is genuinely good or just
looks good.

## How it runs

The entry is a small web app under `app/` (static HTML/CSS/JS), served by
`main.ts`. See the screenshots in `screenshots/` for the desktop and mobile
views.
